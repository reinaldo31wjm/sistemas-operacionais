Comparativo de Arquiteturas de SO
🐧

Linux Kernel

  • Arquitetura: Monolítica modular
  • Escalonador: CFS (Completely Fair Scheduler)
  • Memória: Buddy Allocator + SLAB/SLUB
  • Foco: Servidores, cloud, HPC e Android
🪟

Windows NT

  • Arquitetura: Híbrida
  • Escalonador: Preemptivo por prioridade
  • Memória: VMM com paging file
  • Foco: Desktops, jogos e redes corporativas
🍎

macOS (XNU)

  • Arquitetura: Híbrida (Mach + BSD)
  • Escalonador: Mach Multi-layer Feedback Queue
  • Memória: Mach VM com compressão
  • Foco: Estações de trabalho, áudio e vídeo
