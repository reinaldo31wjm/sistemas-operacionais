Matriz Comparativa de Arquiteturas de SO
🐧

Linux Kernel

  • Arquitetura: Monolítico Modular
  • Escalonador: CFS (Completely Fair Scheduler)
  • Memória: Buddy Allocator + SLAB/SLUB
  • Foco: Servidores, Cloud, HPC, Android
🪟

Windows NT

  • Arquitetura: Híbrido
  • Escalonador: Preemptivo por Prioridade (32 níveis)
  • Memória: VMM com Paging File
  • Foco: Desktops, Jogos, Redes Corporativas
🍎

macOS (XNU)

  • Arquitetura: Híbrido (Mach + BSD Kernel)
  • Escalonador: Mach Multi-layer Feedback Queue
  • Memória: Mach VM com Compressão de Memória
  • Foco: Estações de trabalho, Áudio/Vídeo, UI
