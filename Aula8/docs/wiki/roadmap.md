# roadmap

As próximas evoluções possíveis devem ser avaliadas sem alterar o escopo atual sem documentação:

- adicionar testes automatizados para rotas e coleta;
- melhorar a observabilidade do próprio serviço;
- oferecer retenção histórica opcional;
- integrar alertas externos com autenticação adequada;
- revisar controles de acesso antes de qualquer uso privado ou produtivo.

Estas são possibilidades, não funcionalidades implementadas.
