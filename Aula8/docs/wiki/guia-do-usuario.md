# guia do usuário

1. Abra o [System Monitor público](https://system-monitor-i16u.onrender.com) ou a URL local.
2. Observe os indicadores de CPU, memória, disco, carga e uptime.
3. Use a atualização manual quando precisar de uma nova leitura.
4. Pause a atualização automática quando quiser analisar os valores atuais.
5. Consulte a área de diagnóstico para acompanhar o histórico recente.

As métricas descrevem o ambiente do servidor, contêiner ou plataforma que executa o serviço.
