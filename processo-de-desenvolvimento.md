# processo de desenvolvimento

O fluxo recomendado é:

1. criar uma branch com objetivo claro;
2. alterar código e documentação juntos;
3. validar localmente as rotas principais;
4. abrir Pull Request com evidências;
5. revisar e integrar;
6. publicar e conferir logs e health check.

Os detalhes estão em [processo-devops.md](../processo-devops.md) e no [checklist](../checklist-documentacao.md).
