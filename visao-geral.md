# visão geral

O System Monitor é um painel web de observabilidade para acompanhar o ambiente de execução do serviço. Ele coleta métricas no servidor, expõe os dados por HTTP e apresenta os resultados no navegador.

O projeto foi usado como estudo de caso da Aula 08 para demonstrar como uma documentação pode explicar objetivo, escopo, arquitetura, operação e segurança de uma aplicação real.

Para a visão resumida, consulte o [readme](../../readme.md). Para escopo e requisitos, consulte [documentacao-de-projeto.md](../documentacao-de-projeto.md).
